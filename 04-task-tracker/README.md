# Python To-Do List App

A beginner-friendly task manager built using Python.

## Features
- Add tasks
- View numbered tasks
- Delete tasks
- Handle invalid input
- Menu-driven interface

## Concepts Learned
- Python lists
- loops
- functions
- conditions
- user input
- exception handling.

## How to Run
```bash
python main.py
```
