# Practice Projects 🚀

A collection of beginner-friendly Python mini projects built while learning Python.

## Projects Included

| # | Project | Description |
|---|---------|-------------|
| 01 | [Number Guessing Game](./01-number-guessing-game/) | Guess a randomly generated number with higher/lower hints |
| 02 | [Calculator](./02-calculator/) | Simple calculator that performs +, -, *, / operations |
| 03 | [Password Generator](./03-password-generator/) | Generate secure random passwords |
| 04 | [Task Tracker](./04-task-tracker/) | Menu-driven to-do list application |
| 05 | [Student Performance Manager](./05-student-performance-manager/) | Manage student records, marks, and calculate average |
| 06 | [Expense Tracker](./06-expense-tracker/) | Track expenses with JSON file storage |
| 07 | [File Organizer](./07-file-organizer/) | Automatically organize files by type |

## How to Run Any Project

1. Open the project folder
2. Run the Python file:

```bash
python main.py
```
