# 🎯 Number Guessing Game

A simple Python game where the computer generates a random number and the player tries to guess it.

## ✨ Features
- Random number generation
- User input for guesses
- Hints to guess higher or lower
- Tracks the number of attempts

## 🛠️ Built With
- Python

## 📚 What I Learned
- Using the `random` module
- Working with `while` loops
- Using `if`, `elif`, and `else`
- Taking user input with `input()`
- Converting input using `int()`
- Comparing values with conditional statements
- Tracking attempts using variables
- Building basic game logic

## ▶️ How to Run
```bash
python main.py
```
